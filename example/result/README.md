# **Simulation Results Overview**

This directory contains the output files generated by the Infectiousness-Dependence Coefficient (IDC) agent-based model. The results are systematically organized into three primary subdirectories based on their data resolution and analytical purpose. 

*(Note: The `{n}` suffix in filenames indicates the random seed used for that specific simulation iteration.)*

---

## **1. `tree_detail/` (Agent-Level Network Logs)**
Contains data for reconstructing transmission trees and analyzing individual-level biological traits.
* **`tree{n}.xlsx`**: The directed edge-list of the generational transmission network (who-infected-whom).
* **`Individual_R{n}.xlsx`**: Individual reproduction numbers ($R$) for transmission dispersion and superspreading analysis.
* **`Infectiousness{n}.xlsx`**: Logs the dynamic peak infectiousness (viral load proxies) of transmission pairs, serving as the core dataset for evaluating the IDC mechanism.

---

## **2. `save_sim/` (Aggregated Epidemiological Metrics)**
Contains `output_sim{n}.xlsx`, a comprehensive workbook that aggregates raw agent-level logs into population-level statistics. Key aggregated outputs include:
* **Temporal & Spatial Dynamics**: Daily new infections and cross-layer transmission proportions (Household, School, Workplace, Community).
* **Age-Stratified Metrics**: Cumulative attack rates and a 10x10 age-group transmission matrix.
* **Epidemic Indicators**: Cluster sizes, generation/serial intervals, doubling times, and time-varying effective reproduction numbers ($R_t$).

---

## **3. `sims_detail/` (Standard Model Summaries)**
Contains the native output structures exported directly from the Covasim framework.
* **`sim{n}.xlsx`**: A macro-level epidemiological summary tracking daily population state transitions (e.g., total Susceptible, Exposed, Infectious, Recovered, and Isolated individuals per timestep) for baseline calibration.
